## В корневом каталоге проекта содержаться:
config.py - Централизованное хранение всех настроек и тестовых данных проекта.

pytest.ini - Конфигурационный файл pytest, который задаёт настройки для всех тестов в проекте.

README.md - содержит информацию в целом о проекте.

requirements.txt - Список всех Python-зависимостей проекта с версиями для быстрой установки одной командой.

## Директория pages содержит:

init.py - Пустой файл, который делает папку Python-пакетом, чтобы из неё можно было импортировать модули.

locators.py - Все локаторы элементов страниц

base_page.py - Базовые методы: клик, ввод текста, поиск элемента, ожидание

auth_page.py - Методы для страницы авторизации: табы, поля, кнопки, ошибки

registration_page.py - Методы для страницы регистрации: поля ввода, кнопки, модальные окна

## Директория tests содержит: 

conftest.py - Фикстура driver — запуск и закрытие браузера перед каждым тестом

test_auth_form.py - TC-01 – TC-07: форма авторизации, табы, негативные сценарии

test_auth_by_code.py - TC-08 – TC-12: вход по коду

test_password_recovery.py - TC-13 – TC-18: восстановление пароля, валидация

test_registration.py - TC-19 – TC-22: регистрация нового пользователя

## Инструменты, которые применялись для тестирования

Для тестирования сайта был использован интсрумент Selenium.

Специальный тестовый фреймворк Pytest.

Плагин для pytest, который генерирует HTML-отчет по результатам тестов pytest-html.

Опционально можете установить плагин allure-pytest и скачать для неё командную строку для генерации красивых html-отчётов.

Для определения локаторов использовались следующие инструменты: DevTools, ChroPath.

## Запуск тестов:
установить все библиотеки и зависимости: pip install -r requirements.txt.

убедитесь что у вас присутствуют основные браузеры для тестирования - в файле conftest.py у фикстуры initialize_driver можете изменить браузер.

запустить тесты: pytest tests/ -v

HTML-отчёт: pytest tests/ -v --html=reports/report.html --self-contained-html

запустить по группам: 

pytest -m auth -v

pytest -m reg -v
